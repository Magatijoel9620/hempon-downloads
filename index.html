Can I use Farmora and Landlord Ledger without installing an APK?

Yes. Open the web app links on this page to use Farmora or Landlord Ledger in a supported browser. You can also install the Android versions using their APK links.

Are the apps free to use?

Downloading an APK does not guarantee that every feature is free. Individual products may offer trials, subscriptions or usage limits. Check the relevant app for its current plans and pricing.

Why does Android warn me about an APK?

Android applies additional caution to apps installed outside Google Play. Verify that the download came from the official Hempon Group download page before proceeding.

Can I update an existing Android installation?

Usually, an update can install over the existing app if it uses the same application ID, a compatible signing key and a higher version code. Back up important information before updating.

Can I install these APKs on an iPhone or iPad?

No. APK files are Android installers. On iPhone or iPad, use a web app link where one is available.

What if a download or web app does not open?

Check your connection and try again. For APK downloads, confirm available storage and that the download completed. If the issue persists, visit the Hempon Group website for support information.
